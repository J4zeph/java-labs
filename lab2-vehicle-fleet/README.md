# Лабораторная работа 2 — «Автопарк»

Консольное приложение с иерархией транспортных средств на основе абстрактного класса `Vehicle`.

## Что демонстрирует

- абстрактный класс `Vehicle` и абстрактный метод `move()`;
- наследники `Car`, `Motorcycle`, `Truck` с переопределённым `move()`;
- восходящее преобразование и полиморфизм при обходе массива `Vehicle[]`;
- безопасное нисходящее преобразование через `instanceof`;
- вложенный класс `Vehicle.Engine`;
- анонимный класс (электросамокат в `Main`);
- `final`-метод `printInfo()`.

## Запуск

    javac -encoding UTF-8 *.java
    java Main

Требуется Java 11+.
